# mapac v0.1.0

MacinDecode APAC Core 独立代码仓库的 CLI 发布说明。

## 功能

- Windows x64、Linux x64 和 macOS ARM64 上的独立 APAC 解码、配置／逐包解析和 PCM 比较。
- WAV／RF64／CAF 文件输出、按帧范围解码与快速定位。
- SQ、CAC、TNS、零至十阶 HOA 和源声道还原。
- 默认开启 CAC。BWE2 默认关闭，活跃帧返回 `bwe2-unavailable`。可选数值接口需要用户显式提供外部 LSF 输入。

压缩包内包含程序、使用文档、许可证和 `build-info.json`，相邻 `.sha256` 文件用于核对完整性。
文件名为 `mapac-v0.1.0-TARGET`，Windows 使用 `.zip`，Linux 和 macOS 使用 `.tar.gz`。
构建与验收流程见 [开发说明](../development.md) 和 [验证范围](../validation.md)。

## English

This release belongs to the independent MacinDecode APAC Core repository.
It provides APAC decoding, configuration/packet inspection, PCM comparison, streaming WAV/RF64/CAF output and frame-based access on Windows x64, Linux x64 and macOS ARM64.

CAC is enabled by default. BWE2 is disabled by default and active BWE2 frames return `bwe2-unavailable`.
The optional numerical interface requires explicit external LSF input.
Archives include the executable, documentation, licenses and `build-info.json`, with an adjacent SHA-256 file.
