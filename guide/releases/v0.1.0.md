# apac-tool v0.1.0

MacinDecode-APAC-Core 的首个 CLI 版本。使用独立 Rust 解码器，将 Apple Positional Audio Codec（APAC）音频导出为交错、小端 Float32 PCM，并提供配置解析、逐包语法报告和 PCM 比较。

## 下载与运行

从本版本的 **Assets** 下载对应安装包及同名 `.sha256` 校验文件：

| 平台 | 安装包 | 运行环境 |
| --- | --- | --- |
| Windows x64 | `apac-tool-v0.1.0-x86_64-pc-windows-msvc.zip` | Windows 10／11 x64；CI 在 Windows Server 2022 验证，静态链接 CRT |
| Linux x64 | `apac-tool-v0.1.0-x86_64-unknown-linux-gnu.tar.gz` | glibc 2.35 或更新，例如 Ubuntu 22.04／24.04 |
| macOS arm64 | `apac-tool-v0.1.0-aarch64-apple-darwin.tar.gz` | Apple Silicon；CI 在 macOS 26 验证 |

解压后进入包内目录，运行以下命令；Windows PowerShell 中将 `./apac-tool` 换为 `.\apac-tool.exe`：

```sh
./apac-tool --version
./apac-tool --help
./apac-tool decode-sq input.m4a --out decoded
```

输出为 `decoded/pcm.f32le`、`pcm.json` 和 `decode-sq.json`。`--out` 必须是尚不存在的目录；默认输出上限为 128 MiB，较长音频可按需增加，例如 `--max-output-mib 1024`。原始 PCM 没有 WAV 头；采样率、声道数及布局见 `pcm.json`。

仅解码指定范围：

```sh
./apac-tool decode-sq input.caf --out window \
  --start-frame 480000 --frames 8192 --access fast
```

包内附中英文 README、完整 `guide/`、MIT／Apache-2.0 许可证、第三方来源说明和 `build-info.json`，后者记录构建提交、编译器版本、目标平台和可执行文件 SHA-256。使用预构建 CLI 无需安装 Rust。

## 首版能力

- 输入：CAF v1、非分片单音轨 MP4／M4A，以及经过校验的导出包目录。
- 声道解码：Mono、Stereo、5.1、7.1、7.1.4、9.1.6 和 22.2；包含 SQ、CAC、TNS、BWE2 和合成，安装包默认开启 CAC。
- HOA：零至三阶，含 salient／ambient、动态选择、源布局还原和受支持的组合流。
- 跨平台命令：`decode-sq`、`parse-cookie`、`parse-packets`、`compare`。
- macOS 额外提供基于 AudioToolbox 的参考采集、编码、解码及回放命令；日常独立解码使用 `decode-sq`。

## 已知边界

- 输出为 PCM；不提供 GUI、音频播放、空间渲染、WAV 封装或其他编码格式转码。
- DRC、响度和 EQ 只解析元数据，不施加音频处理。
- 四阶及以上 HOA、LRVQ、外层 ASP 重配置、非零帧长索引及其他未支持的配置会明确报错。
- 不支持分片 MP4、多音轨 MP4、加密／DRM 输入；macOS 首版只提供 Apple Silicon 安装包。
- 采用独立、固定的数值模型，设计上不与苹果 AudioToolbox 逐位一致。

详见包内的 `guide/commands.md`、`guide/decoding.md` 和 `guide/support.md`。

## English

The first CLI release of MacinDecode-APAC-Core. `apac-tool` independently decodes APAC CAF, unfragmented single-audio-track MP4/M4A, and validated packet bundles into interleaved little-endian Float32 PCM. It supports mono through 22.2 channel layouts (including 9.1.6), HOA orders zero through three, configuration and packet inspection, and PCM comparison. CAC is enabled in all release packages.

Download the archive for Windows x64, Linux x64 (glibc 2.35+), or Apple Silicon macOS, verify its adjacent SHA-256 file, and extract it. macOS builds are tested on macOS 26; Windows builds are tested on Windows Server 2022 and statically link the CRT. Run `./apac-tool decode-sq input.m4a --out decoded` (PowerShell: `.\apac-tool.exe`). No Rust installation is required. The output directory must not already exist; the default output limit is 128 MiB, adjustable with `--max-output-mib`.

Output is raw PCM with JSON metadata, not a WAV file. This release does not include a GUI, audio playback, spatial rendering, DRC/loudness/EQ processing, or other-format encoding. HOA above third order, LRVQ, fragmented/multi-track/encrypted MP4 and unsupported configurations are rejected. The decoder follows its own numeric model and is not bit-identical to Apple's reference. AudioToolbox reference commands are available only on macOS.
