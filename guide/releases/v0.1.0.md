## 简体中文

MacinDecode APAC Core **v0.1.0** 是本项目的首个命令行版本。下载 `apac-tool`，即可在 Windows、Linux
和 macOS 上解码 APAC 空间音频，导出 PCM，或查看配置与逐包语法。欢迎通过
[Issues](https://github.com/SakuzyPeng/MacinDecode-APAC-Core/issues) 反馈使用中遇到的问题。

### 下载与使用

在本页下方的 **Assets** 中选择适合你的压缩包：

| 你的电脑 | 下载哪个文件 |
| --- | --- |
| Windows 10／11，Intel / AMD 64 位电脑 | 以 `x86_64-pc-windows-msvc.zip` 结尾的文件 |
| Linux，Intel / AMD 64 位电脑，glibc 2.35 或更新（如 Ubuntu 22.04） | 以 `x86_64-unknown-linux-gnu.tar.gz` 结尾的文件 |
| Apple 芯片 Mac（M1 及更新机型；当前在 macOS 26 验证） | 以 `aarch64-apple-darwin.tar.gz` 结尾的文件 |

解压即可使用，无需安装 Rust 或其他解码器，也不需要管理员权限。这是命令行程序，请在终端中运行。
同名 `.sha256` 附件用于核对下载是否完整，无需安装；包内已附使用文档、许可证和构建信息。

### 首版能做什么

- **解码 APAC 文件**：直接读取含 APAC 音轨的 `.m4a`、`.mp4` 和 `.caf`，也可读取导出的包目录。
  支持单声道、立体声、5.1、7.1、7.1.4、9.1.6 和 22.2，保持输入采样率和声道布局。
- **导出 HOA 音频**：支持零至三阶，可输出 ACN/SN3D 系数，或还原码流声明的源声道。
- **提取短片段**：按音频帧指定起点和长度，也可用 `--access fast` 快速访问长文件中的一段。
- **查看和比较**：解析配置、逐包查看语法，比较两份 PCM 的格式、布局和逐声道误差。
  macOS 另外提供 AudioToolbox 参考采集、编解码和回放工具。

### 第一次解码

1. 解压下载的压缩包，在终端中进入包含 `apac-tool` 的目录。
2. 运行下面对应平台的命令，把 `input.m4a` 换成你的 APAC 文件路径。
3. 成功后打开 `decoded/pcm.json` 查看采样率、声道数和布局，音频数据在 `decoded/pcm.f32le`。

**Windows PowerShell：**

```powershell
.\apac-tool.exe --version
.\apac-tool.exe decode-sq "input.m4a" --out decoded
```

**macOS / Linux：**

```sh
./apac-tool --version
./apac-tool decode-sq "input.m4a" --out decoded
```

`decoded` 必须尚不存在。默认输出上限为 **128 MiB**；较长文件或多声道音频可在命令后添加
`--max-output-mib 1024`，按需提高上限。输出是**交错、小端 32 位浮点原始 PCM**，不带 WAV 文件头；
导入音频工具时请使用 `pcm.json` 中的采样率和声道数。

更多操作见[中文上手说明](https://github.com/SakuzyPeng/MacinDecode-APAC-Core/blob/v0.1.0/README.md)、
[命令行参考](https://github.com/SakuzyPeng/MacinDecode-APAC-Core/blob/v0.1.0/guide/commands.md)和
[解码指南](https://github.com/SakuzyPeng/MacinDecode-APAC-Core/blob/v0.1.0/guide/decoding.md)。这些文档也在压缩包内。

### 使用前了解

- 只支持 APAC 音频，普通 AAC `.m4a`、MP3 和 FLAC 不受支持。MP4／M4A 当前限非分片、单音轨文件，不支持加密／DRM 输入。
- CLI 导出音频，不播放声音。HOA 系数还需要空间渲染；本工具不提供 GUI、空间渲染、WAV 封装或其他格式编码。
- DRC、响度和 EQ 只解析元数据，不施加音频处理。解码器采用独立数值模型，设计上不与苹果 AudioToolbox 逐位一致。
- 四阶及以上 HOA、LRVQ、外层 ASP 重配置及非零帧长索引暂不支持，遇到时会明确报错。
- 使用独立解码时请运行 `decode-sq`；`decode` 是仅在 macOS 可用的参考命令。macOS 首版只提供 Apple Silicon 产物。

遇到问题时，请提供程序版本、操作系统、使用的命令和错误提示，提交前去掉个人路径。
完整支持范围见[支持边界](https://github.com/SakuzyPeng/MacinDecode-APAC-Core/blob/v0.1.0/guide/support.md)。

## English

MacinDecode APAC Core **v0.1.0** is the project's first command-line release. Download `apac-tool` to
decode APAC spatial audio, export PCM, and inspect configuration and packet syntax on Windows, Linux
and macOS. Please report problems through [Issues](https://github.com/SakuzyPeng/MacinDecode-APAC-Core/issues).

### Download and run

Choose an archive from **Assets** at the bottom of this page:

| Your computer | File to download |
| --- | --- |
| Windows 10/11, 64-bit Intel / AMD PC | The file ending in `x86_64-pc-windows-msvc.zip` |
| Linux, 64-bit Intel / AMD PC, glibc 2.35 or later (such as Ubuntu 22.04) | The file ending in `x86_64-unknown-linux-gnu.tar.gz` |
| Apple silicon Mac (M1 or newer; currently tested on macOS 26) | The file ending in `aarch64-apple-darwin.tar.gz` |

Extract the archive and run the program from a terminal. No Rust installation, additional decoder or
administrator rights are required. The adjacent `.sha256` file verifies the download and does not need
to be installed. Documentation, licenses and build information are included in the archive.

### What this release can do

- **Decode APAC files:** read APAC `.m4a`, `.mp4` and `.caf` directly, or use exported packet bundles.
  Mono, stereo, 5.1, 7.1, 7.1.4, 9.1.6 and 22.2 retain their input sample rate and channel layout.
- **Export HOA audio:** orders zero through three, as ACN/SN3D coefficients or the source channels declared by the stream.
- **Extract a short passage:** specify a start frame and length, with `--access fast` for fast range access in longer files.
- **Inspect and compare:** parse configuration, examine packet syntax, and compare PCM format, layout and per-channel errors.
  macOS also includes AudioToolbox reference collection, encoding, decoding and replay tools.

### Your first decode

1. Extract the download and open a terminal in the directory containing `apac-tool`.
2. Run the commands for your platform below, replacing `input.m4a` with the path to your APAC file.
3. On success, open `decoded/pcm.json` for the sample rate, channel count and layout. Audio data is in `decoded/pcm.f32le`.

**Windows PowerShell:**

```powershell
.\apac-tool.exe --version
.\apac-tool.exe decode-sq "input.m4a" --out decoded
```

**macOS / Linux:**

```sh
./apac-tool --version
./apac-tool decode-sq "input.m4a" --out decoded
```

`decoded` must not already exist. The default output limit is **128 MiB**; append `--max-output-mib 1024`
to raise it for longer files or multichannel audio. Output is **interleaved little-endian 32-bit floating-point
raw PCM**, without a WAV header. When importing it into an audio tool, use the sample rate and channel
count from `pcm.json`.

See the [English quickstart](https://github.com/SakuzyPeng/MacinDecode-APAC-Core/blob/v0.1.0/README.en.md),
[command reference](https://github.com/SakuzyPeng/MacinDecode-APAC-Core/blob/v0.1.0/guide/commands.md) and
[decoding guide](https://github.com/SakuzyPeng/MacinDecode-APAC-Core/blob/v0.1.0/guide/decoding.md) for more options.
The detailed guides are in Chinese. All these documents are included in the archive.

### Before you start

- Input must contain APAC audio. Ordinary AAC `.m4a`, MP3 and FLAC are unsupported. MP4/M4A is limited to unfragmented, single-audio-track files; encrypted/DRM input is unsupported.
- The CLI exports audio without playing it. HOA coefficients still need spatial rendering. There is no GUI, spatial renderer, WAV writer or encoder for other formats.
- DRC, loudness and EQ metadata are parsed without processing audio. The decoder uses its own numeric model and is not bit-identical to Apple's AudioToolbox reference by design.
- HOA above third order, LRVQ, outer ASP reconfiguration and nonzero frame-length indices are not supported and fail explicitly.
- Use `decode-sq` for independent decoding. `decode` is the macOS-only reference command. The first macOS release is Apple Silicon only.

When reporting a problem, include the program version, operating system, command and error message,
with personal paths removed. See [support boundaries](https://github.com/SakuzyPeng/MacinDecode-APAC-Core/blob/v0.1.0/guide/support.md)
for the full scope.
